# Pokédex

A Pokémon encyclopedia — a vanilla JavaScript project built for learning purposes.

---

## About

Pokédex lets you browse Pokémon pulled live from the [PokeAPI](https://pokeapi.co), search for a specific one by name or ID and open a detail view for any of them. The detail dialog shows the official artwork, the Pokémon's types and its base stats, and you can page through the entire roster from inside it without closing it. Built without any framework or library — plain HTML, CSS and JavaScript. Every card and dialog is reachable by keyboard and carries proper ARIA labels.

---

## Features

- **All 1025 Pokémon**, loaded 20 at a time
- **Search by name or ID**
- **Detail dialog with base stats**
- **Previous / next navigation**
- **Type-based coloring across all 18 types**
- **Fluid responsive design**
- **ARIA labels and keyboard navigation**

## Getting Started

No setup or installation required.

1. Clone or download the repository
2. Open `index.html` in your browser

That's it. An internet connection is needed, since all Pokémon data is fetched live from the PokeAPI.
